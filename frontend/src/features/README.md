# Features

Domain feature modules go here — one directory per bounded feature
(e.g. `rule-builder/`, `service-requests/`), each owning its own
components, hooks, and API calls for that feature.

Feature-specific modules remain mostly empty. Authentication-gated app
views and the Operations list/detail flow live in `src/app` and
`src/components`; a Rule Builder and tenant catalog administration UI are
not part of the current scope.
